## ⚡ Deployment (5 Minutes)

### Step 1: Push to GitHub

Ensure your code is pushed to your `main` branch.

### Step 2: Create Blueprint

1. Go to [dashboard.render.com/blueprint](https://dashboard.render.com/blueprint/new)
2. **Connect GitHub Repo**: Select your repo
3. **Approve**: Click "Apply"

Render will automatically read `render.yaml` and create:

- ✅ **pulsekart-db** (PostgreSQL Database)
- ✅ **pulsekart-api** (Backend Service)
- ✅ **pulsekart-web** (Frontend Service)

**Wait 5-10 minutes** for the build to finish. ☕

## 🌐 Domain Setup (Migrating from Vercel)

Moving your custom domain to Render is simple.

### Step 1: Remove from Vercel (Important!)

To avoid conflicts, you must first remove the domain from Vercel:

1. Go to your Vercel Dashboard → Project Settings → **Domains**.
2. Remove your custom domain (e.g., `www.yourdomain.com`).

### Step 2: Add to Render

1. Go to your Render Dashboard.
2. Click on the **pulsekart-web** (Frontend) service.
3. Go to **Settings** → **Custom Domains**.
4. Click **Add Custom Domain** and enter `www.yourdomain.com`.

### Step 3: Update DNS

Go to your domain provider (GoDaddy, Namecheap, etc.) and update your DNS records:

| Type | Name | Value |
|------|------|-------|
| CNAME | `www` | `pulsekart-web.onrender.com` |
| ANAME (or ALIAS) | `@` | `pulsekart-web.onrender.com` |

*Note: SSL certificates are automatically generated by Render once verified.*

## ⚠️ Common Issues

### CORS Errors

If you see CORS errors, check the `ALLOWED_ORIGINS` environment variable in the Backend service.
We set it to `*` by default for ease of use.

### 502 Bad Gateway

If the backend shows 502, it might still be starting up. Check the **Logs** tab.

### Database Connection

The blueprint automatically links the database. You don't need to do anything!
